# Phase 0001: Native Haiku Skeleton

Goal: create the smallest useful BeSqlitEd application that proves the native direction.

## Must Have

- Native BApplication
- Native BWindow
- Open SQLite database file
- List schema objects
- Execute a simple SQL query
- Show results in a minimal native view or diagnostic output

## Must Not Have

- Qt
- KDE
- GTK
- MDI
- Docking
- Plugin system
- Theme system
- Full SQL editor
- Full result grid
- Table editor

## Success Definition

A Haiku user can open BeSqlitEd, select a SQLite database, and see that the application belongs to Haiku rather than merely running on Haiku.
