# BeSqlitEd

**BeSqlitEd** — a Haiku-native SQLite editor and workbench. Be-native. SQLite-focused. Editor-minded.

The name combines:

- **Be** — the BeOS/Haiku heritage
- **SQLite** — the database engine
- **Ed** — editor / editing tool

It is pronounced like “Be SQLite-ed”, but written to emphasize its role as a native SQLite editor.
